دیدبان؛ نبض سایت وردپرسی خود را زیر نظر بگیرید.
Didban is a free Persian WordPress plugin designed to help website owners understand visitor activity, monitor website performance, and track important events through a visual dashboard.

دیدبان با هدف ارائه ابزار تحلیل و نظارت ساده و کاربردی برای مدیران سایت‌های فارسی‌زبان توسعه داده شده است.

---

## ✨ Features | امکانات

### 📊 Visitor Analytics
- Track website visitors
- Monitor visitor IP addresses
- Measure session duration
- Analyze visitor activity

### 📱 Device Statistics
- Monitor visitor devices
- View device statistics
- Analyze visitor access patterns

### 📈 Page Analytics
- Identify the most visited pages
- Analyze popular website content
- Track page visits

### 🛒 Order Monitoring
- Monitor website orders
- Track order activity
- Review order statistics

### 🔐 Login Monitoring
- Track failed login attempts
- Monitor unsuccessful access attempts
- Review login activity

### 🎨 Visual Dashboard
- Clean and modern interface
- White and blue visual identity
- Charts and statistical reports
- Persian language interface

---

## 🇮🇷 Built for Persian WordPress Websites

Didban is designed with Persian-speaking WordPress users in mind, providing an accessible interface for website monitoring and analytics.

## 📦 Installation

1. Download the latest release.
2. Open your WordPress Dashboard.
3. Navigate to Plugins → Add New Plugin.
4. Click Upload Plugin.
5. Select the Didban ZIP file.
6. Install and activate the plugin.

## 🔒 Privacy & Security

Didban may process visitor IP addresses, device information, session activity and login events.

Website administrators should disclose applicable data collection in their privacy policy, protect access to analytics data, and configure appropriate data retention practices.
